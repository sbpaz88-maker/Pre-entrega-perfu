## Pre-entrega Front-End: Bella Paz - Cosmética & Estética

Armé la pre-entrega de la web orientada a un emprendimiento o e-commerce de cosmética y cuidado personal. Siempre me apasionó el mundo del skincare y los cosméticos, por lo que quise diseñar una landing page limpia, delicada y ordenada para presentar productos destacados y canales de atención.

## El proyecto incluye:
- HTML5 (Estructura semántica básica con secciones de inicio, productos y contacto)
- CSS3 (Diseño responsivo en tonos rosas, estilos propios con Flexbox para el catálogo de productos y maquetado general)
